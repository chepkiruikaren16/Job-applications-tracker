# Job Applications Tracker

#About The Project

Job Applications Tracker is a web application that helps job seekers organize and manage their job search in one place. Users can add job applications, track application progress, monitor deadlines, record interview dates, and store important notes.

The applications uses JavaScript and the browser LocalStorage API to save application data, allowing information to remain available even after refreshing the page.

#Features

- Add new job applications
- Save applications automatically
- View all applications
- Edit application details
- Delete applications
- Search applications by company name or job title
- Filter applications by status
- Track application deadlines
- Track interview dates
- Add recruiter information
- View dashboard statistics
- Responsive modern user interface

#Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server.

The purpose of this project is to provide a simple and effective way for job seekers to manage their applications, stay organized, and track their career opportunities.
