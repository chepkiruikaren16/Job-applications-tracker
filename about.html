About CareerFlow

CareerFlow is a simple and user-friendly Job Application Tracker designed to help job seekers organize and manage their job search. Instead of keeping application details in notebooks or spreadsheets, CareerFlow stores everything in one place, making it easier to monitor applications and deadlines.

Project Objectives

📋 Organize

Keep all job applications in one place with important details such as company name, job title, recruiter information, and notes.

📅 Track

Monitor application dates, deadlines, interview schedules, and application status.

📈 Improve

View statistics to understand your job search progress and stay motivated throughout your career journey.

Technologies Used

HTML5

Semantic HTML was used to structure the web pages.

CSS3

CSS provides the responsive layout, styling, and animations.

JavaScript

JavaScript powers localStorage, search, filtering, dashboard statistics, and application management.
